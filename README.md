## 📖 Project Description
**MatchaHolic** is an application developed to fulfill the Midterm Exam (UTS) requirement. This application focuses on presenting a catalog of matcha-based products, ranging from beverages to snacks, and is equipped with a simple ordering feature.

## ✨ Key Features
*   **User Authentication:** User Login and Registration.
*   **Product Catalog:** Displays various matcha product variants along with their prices and descriptions.
*   **Shopping Cart:** Users can add products to their cart before proceeding to checkout.
*   **Profile Management:** Users can manage their profile information.
*   **Responsive UI:** A user interface designed to be neat, responsive, and comfortable to use.
