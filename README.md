## 📖 Project Description

**MatchaHolic** is a Flutter-based social networking application developed to fulfill the Midterm Exam (UTS) requirement. Inspired by platforms like Facebook, this app allows users to connect with friends, share updates, and interact within a matcha-themed community.

This is a **group project consisting of 3 members**, where each member contributes by sharing responsibilities across different parts of the application — from UI development to backend integration and testing.

> ⚠️ This repository is a fork of [mathewrs04/MatchaHolicProjectUTS](https://github.com/mathewrs04/MatchaHolicProjectUTS).

---

## ✨ Key Features

- **User Authentication:** User Login and Registration
- **Friend System:** Send, accept, and manage friend requests (like Facebook)
- **Feed / Timeline:** View posts and updates from friends
- **Post Creation:** Share text updates or content to your feed
- **Profile Management:** View and edit your personal profile
- **Responsive UI:** Clean and comfortable UI across different screen sizes

## 🚀 How to Run (Installation)

### Prerequisites

- Flutter SDK installed ([flutter.dev](https://flutter.dev))
- Android Studio or VS Code with Flutter plugin
- A running backend server (if applicable)

### Steps

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/AudryVerly/MatchaHolicProjectUTS.git
   ```

2. **Navigate to the Project Directory:**
   ```bash
   cd MatchaHolicProjectUTS
   ```

3. **Install Flutter Dependencies:**
   ```bash
   flutter pub get
   ```

4. **Environment Configuration:**
   - Open `lib/` and adjust the base URL or API endpoint to point to your backend server.

5. **Run the Application:**
   ```bash
   flutter run
   ```
   - Connect a device or start an emulator before running.
