## 📖 Project Description
**MatchaHolic** is an application developed to fulfill the Midterm Exam (UTS) requirement[cite: 1]. This application focuses on presenting a catalog of matcha-based products, ranging from beverages to snacks, and is equipped with a simple ordering feature[cite: 1].

## ✨ Key Features
*   **User Authentication:** User Login and Registration[cite: 1].
*   **Product Catalog:** Displays various matcha product variants along with their prices and descriptions[cite: 1].
*   **Shopping Cart:** Users can add products to their cart before proceeding to checkout[cite: 1].
*   **Profile Management:** Users can manage their profile information[cite: 1].
*   **Responsive UI:** A user interface designed to be neat, responsive, and comfortable to use[cite: 1].

## 🛠️ Tech Stack

*   **Database:** MySQL / SQLite[cite: 1]

## 🚀 How to Run (Installation)

Follow the steps below to run the project locally on your device[cite: 1]:

1. **Clone the Repository:**
```bash
   git clone [https://github.com/mathewrs04/MatchaHolicProjectUTS.git](https://github.com/mathewrs04/MatchaHolicProjectUTS.git)
   ```
2. **Navigate to the Project Directory:**
```bash
   cd MatchaHolicProjectUTS
   ```
3. **Install Dependencies:**
*If using Laravel:*
```bash
   composer install
   npm install
   ```
*If using Flutter:*
```bash
   flutter pub get
   ```
4. **Environment Configuration:**
   *   Copy the `.env.example` file to `.env`[cite: 1]
   *   Adjust your database credentials inside the `.env` file[cite: 1]
5. **Database Migration:**
```bash
   php artisan migrate --seed
   ```
6. **Run the Application:**
```bash
   php artisan serve  # For Laravel
   # or
   flutter run       # For Flutter
   ```
